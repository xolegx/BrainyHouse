
# Умный дом

Проект "Умный дом" — это приложение, разработанное на FastAPI, которое позволяет управлять умными устройствами в вашем доме. Это API позволяет пользователям контролировать и настраивать устройства, управлять пользователями и изменять настройки системы.

## Установка

1. Клонируйте репозиторий:
   
 git clone https://github.com/xolegx/BrainyHouse.git
   cd BrainyHouse

2. Установите зависимости:
   
   pip install -r requirements.txt

3. Настройте базу данных в файле app/db/database.py.

## Использование

Запустите приложение с помощью команды:
uvicorn app.main:app reload

Теперь вы можете получить доступ к API по адресу http://127.0.0.1:8000.

## API

### Устройства

- **GET /devices** - Получить список всех устройств.
- **POST /devices** - Добавить новое устройство.
- **GET /devices/{device_id}** - Получить информацию об устройстве по ID.
- **PUT /devices/{device_id}** - Обновить информацию об устройстве.
- **DELETE /devices/{device_id}** - Удалить устройство.

### Пользователи

- **GET /users** - Получить список всех пользователей.
- **POST /users** - Добавить нового пользователя.
- **GET /users/{user_id}** - Получить информацию о пользователе по ID.
- **PUT /users/{user_id}** - Обновить информацию о пользователе.
- **DELETE /users/{user_id}** - Удалить пользователя.

### Настройки

- **GET /settings** - Получить текущие настройки.
- **PUT /settings** - Обновить настройки.

## Структура проекта

Структура проекта организована по модулям для удобства разработки и поддержки. Основные директории включают:

- **app/** - Основная логика приложения.
- **api/** - Эндпоинты для взаимодействия с приложением.
- **models/** - Модели данных.
- **services/** - Бизнес-логика.
- **db/** - Настройки базы данных.
